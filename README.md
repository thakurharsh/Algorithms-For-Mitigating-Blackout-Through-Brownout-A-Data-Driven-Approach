# Algorithms-For-Mitigating-Blackout-Through-Brownout-A-Data-Driven-Approach
This project focuses on mitigating blackouts through a brownout strategy by imposing power consumption limits. It includes algorithms for fair power allocation and a hybrid algorithm to minimize user inconvenience, tested on real-world datasets using Python, NumPy, and data science tools.
This repository contains the implementation of algorithms for fair power allocation to mitigate blackouts through a brownout strategy. The project, published in IEEE, leverages Python, NumPy, Matplotlib and various data science tools to achieve significant reductions in user inconvenience.

📄 Publication
The work has been published in the IEEE under the title:
"Developing Algorithms to Allocate Power Thresholds"
Access the publication here: [IEEE Xplore](https://ieeexplore.ieee.org/document/10431313/)

📝 Abstract
Blackouts or power outages disrupt critical economic activities, pose public safety risks, and cause significant inconvenience. This project proposes a brownout solution, where power consumption limits are imposed on consumers. The developed algorithms ensure fair allocation of available power, with a hybrid algorithm achieving minimal user inconvenience. Tested on real-world datasets, these approaches reduced violations to as low as 17-20%.

📦 Features
Fair Power Allocation Algorithms: Distributes power equitably among consumers.
Hybrid Algorithm: Minimizes user inconvenience with optimized power thresholds.
Data-Driven Approach: Tested on real-world datasets for two regions.
Python Tools: Utilizes Python, NumPy, Matplotlib and mathematical modeling for robust analysis.

📊 Results
The hybrid algorithm achieved:

Violation reduction: 17-20% compared to traditional methods.
Minimal inconvenience: Optimized thresholds for end-users.
